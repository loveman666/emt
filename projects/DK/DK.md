# 策略名：DK

> 参考 **东方财富 DK 指标** 实现的择时买卖点策略。

---

## 一、DK 指标是什么

DK 是东方财富 App 内置的**择时买卖点指标**，名字取自"**D**uo（多）"与"**K**ong（空）"拼音首字母，即**多空指标**。它在 K 线图上直接标注买卖点：

- **D（买点）**：多头信号，通常标"D"字并伴向上箭头（红色）。
- **K（卖点）**：空头信号，通常标"K"字并伴向下箭头（绿色）。

其定位是给普通投资者一个**直观的高低点提示**。本质上属于**摆动型（震荡）指标 + 状态机翻转**的组合，而非简单的均线交叉。

> **重要说明**：DK 是东方财富**未公开**的指标，官方从未发布精确公式。本文所述为社区根据其行为**逆向拟合**、被广泛验证、拟合度较高的**通行近似原理**，用于策略实现的起点。

---

## 二、核心设计思想

DK 要解决的问题：**如何在趋势相对低位给买点、相对高位给卖点，并减少震荡市里的反复假信号**。它由三个层次组成：

### 1. 用"价格在近期区间中的位置"衡量高低
核心思路与 **William %R / KDJ 的 RSV** 一致：

```
RSV = (Close - LLV(Low, N)) / (HHV(High, N) - LLV(Low, N)) * 100
```

- `LLV(Low, N)`：最近 N 日最低价的最低值
- `HHV(High, N)`：最近 N 日最高价的最高值
- RSV → 0：价格处于区间底部（潜在买点）
- RSV → 100：价格处于区间顶部（潜在卖点）

### 2. 用多重平滑过滤噪声
直接使用 RSV 非常毛躁，因此对其做**多次移动平均（SMA/EMA 平滑）**，得到平滑的"多空能量线"，同理于 KDJ 中 K、D 的递推平滑：

```
Var    = SMA(RSV, M1, 1)
Signal = SMA(Var, M2, 1)
```

### 3. 用"状态翻转 + 阈值"确定唯一买卖点（关键差异）
DK 与 KDJ 最大不同：**它不在每次金叉死叉都发信号，而是维护"当前是多头还是空头"的状态，仅在状态真正翻转的那一根 K 线标注 D 或 K。**

```
若 当前为空头状态 且 能量线于低位向上突破:
    标记 D（买点），状态切换为多头

若 当前为多头状态 且 能量线于高位向下跌破:
    标记 K（卖点），状态切换为空头
```

由此保证 **D、K 交替出现**（一个买点后必先出一个卖点才会再出买点），避免连续买 / 连续卖，这正是 DK 在图上"干净"的原因。

## 三、可落地的近似公式（通行版）

以下为社区流传、拟合东财 DK 较好的公式，作为策略实现起点：

```
N := 34;             {区间回看周期}
M := 5;              {平滑周期}

{1. 计算区间位置}
LLV_N := LLV(LOW, N);
HHV_N := HHV(HIGH, N);
RSV   := (CLOSE - LLV_N) / (HHV_N - LLV_N) * 100;

{2. 多重平滑得到多空线}
DK  := SMA(RSV, M, 1);
MDK := SMA(DK, M, 1);      {信号线}

{3. 翻转判断}
买点 D: CROSS(DK, MDK) AND DK < 低位阈值;    {低位金叉}
卖点 K: CROSS(MDK, DK) AND DK > 高位阈值;    {高位死叉}
```

不同版本的主要差异：

| 项 | 常见取值 / 说明 |
|----|----------------|
| `N`（区间周期） | 21 / 34 / 55，越大越慢越稳 |
| 平滑方式 | `SMA(x, m, 1)` 或 EMA |
| 阈值过滤 | 加低位 / 高位阈值可显著减少震荡市假信号 |

## 四、实战特性与注意点

| 特性 | 说明 |
|------|------|
| **优点** | 信号直观、买卖交替；在**趋势明显**的行情里高低点抓取效果较好 |
| **缺点** | 属**滞后指标**，翻转确认需时间；**震荡 / 横盘**市易在小区间反复给点 |
| **参数敏感** | `N` 与阈值直接决定信号频率，需针对标的与周期做参数优化 |
| **未来函数风险** | `SMA(x,m,1)` 递推不含未来函数；`HHV/LLV` 须确保仅使用**当日及之前**数据 |
| **不宜单用** | 建议叠加**成交量 / 趋势过滤（MA、ADX）**，仅在趋势方向上采用 DK 信号 |

## 五、策略实现思路（掘金量化 gm.api）

当前 `projects/DK/main.py` 为掘金量化空模板，落地为回测策略的思路：

1. **数据订阅**：在 `init` 中订阅日线 / 分钟线数据。
2. **指标计算**：在数据回调中维护 `HHV/LLV`，递推平滑出 `DK` / `MDK`。
3. **状态机**：维护多空状态，翻转时用 `order_target_percent` 建仓 / 清仓。
4. **回测参数**：初始资金、佣金、滑点等已在 `main.py` 的 `run(...)` 中配置。

### 待定 / 可优化项

- [ ] 单标的 vs 多标的、日线 vs 分钟线
